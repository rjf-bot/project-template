# Agent Docs

Esta pasta centraliza a documentação operacional consumida por agentes e por humanos que mantêm as instruções do repositório.

## Conteúdo esperado

- convenções de triagem;
- fluxo do issue tracker local;
- acordos de linguagem e nomenclatura;
- regras de atualização de contexto de domínio;
- políticas para criação e revisão de skills.

## Papel desta pasta no workflow

As skills de spec, tickets, implementação e revisão dependem desta documentação para operar com previsibilidade.

Esta pasta deve responder, no mínimo:

- onde specs e tickets vivem;
- quais labels e estados existem;
- como o agente deve publicar artefatos locais;
- quais documentos são fonte de verdade para domínio e arquitetura.
