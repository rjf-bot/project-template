# Triage Labels

Este arquivo mapeia os rótulos canônicos usados por skills e agentes para os rótulos reais do projeto.

| Papel canônico | Label no projeto | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Item precisa de avaliação inicial |
| `needs-info` | `needs-info` | Faltam informações para seguir |
| `ready-for-agent` | `ready-for-agent` | Item pronto para execução por agente |
| `ready-for-human` | `ready-for-human` | Item requer intervenção humana |
| `wontfix` | `wontfix` | Item não será tratado |

Ajuste a coluna `Label no projeto` para refletir o vocabulário real adotado pelo time.
