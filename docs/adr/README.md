# ADRs

Esta pasta guarda as Architecture Decision Records do projeto.

## Quando criar uma ADR

Crie uma ADR quando a decisão:

- alterar a arquitetura do sistema;
- introduzir um padrão que outras equipes precisarão seguir;
- substituir uma abordagem relevante por outra;
- tiver impacto duradouro em operação, manutenção ou custo.

## Convenção

- Use prefixo numérico crescente: `0001-...`, `0002-...`.
- Não reescreva ADRs antigas para apagar histórico; crie uma nova ADR quando a decisão mudar.
- Referencie ADRs relacionadas no corpo do documento.
